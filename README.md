# Нейробазар — КР №2

**Тема:** CSS-фреймворки: разработка интерфейса на Bootstrap.

**Автор:** Мукаев Вильдан Рустамович  
**Группа:** ЭФБО-06-25

Учебный интернет-магазин шести нейросетей с вымышленными ценами в казахстанских тенге. Это отдельная реализация того же магазина на Bootstrap, а не переделка HTML/CSS-варианта КР №1.

## Страницы

- `index.html` — главная страница, hero, преимущества и популярные товары.
- `catalog.html` — каталог с шестью карточками и ссылками на категории.
- `product.html` — описание и таблицы характеристик товаров.
- `order.html` — форма учебной заявки и вопросы.

## Bootstrap

Используется **Bootstrap 5.3.8**, подключённый через CDN jsDelivr. CSS фреймворка подключён перед `css/custom.css`, а JS Bundle — перед `js/site.js` в конце страниц.

Компоненты: `navbar`, `card`, `btn`, `badge`, `alert`, `modal`, `accordion`, `form-control`, `form-select`, `input-group`, `form-check`. Сетка строится на `container`, `row`, `col-12`, `col-md-*`, `col-lg-*`, `g-*`.

## Самостоятельные доработки

Единый фирменный стиль в `css/custom.css`, адаптивный каталог, подробные характеристики всех шести нейросетей, кнопка заявки с автоматическим выбором товара, раскрывающиеся вопросы, проверка формы без передачи данных.

## Запуск

Откройте `index.html` в браузере при подключении к интернету (Bootstrap загружается через CDN). Сервер и установка зависимостей не нужны.

Логотипы взяты из [Lobe Icons](https://github.com/lobehub/lobe-icons), источник и лицензия указаны в `images/`. Названия и логотипы принадлежат их правообладателям.
